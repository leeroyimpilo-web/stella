# STELLA: The Silence Between Stars

STELLA is a native Android cinematic sci-fi interactive fiction game.

## Design goal
The player should feel inside an interactive science-fiction film: cinematic framing, timed text, reactive sound, haptics, branching decisions, exploration and consequence.

## Development rule
The full game systems and story are built first. Final pixel artwork is produced only after the game is playable end-to-end. Until then, scenes use cinematic placeholder rendering.

## Android
- Native Kotlin
- Jetpack Compose
- Offline-first
- Android 8.0+ (API 26)
- Adaptive portrait/landscape UI
- Local save/continue
- GitHub Actions APK builds

## Current milestone
Foundation + playable opening sequence.
